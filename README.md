# Legolcsóbb repülőjáratok

A projekt célja a leglcsóbb repülőjáratok megkeresése. A keresés után a felhasználó fel tud iratkozni az árváltozásokra.

## Rendszerspecifikáció

A rendszernek képesnek kell lennie arra, hogy több légitársaság és foglalási platform árait egyidejűleg lekérdezze és összehasonlítsa. A felhasználók induló és célrepülőtér, valamint dátumintervallum alapján kereshessenek járatokat. A rendszer értesítse a feliratkozott felhasználókat e-mailben, amint a figyelt járat ára csökken vagy emelkedik. Az adatokat a rendszer rendszeres időközönként frissítse, hogy a megjelenített árak naprakészek legyenek.
