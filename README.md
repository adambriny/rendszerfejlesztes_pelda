# A legolcsóbb repülőjáratok

A projekt célja a legolcsóbb repülőjáratok megkeresése. A keresés után a felhasználó fel tud iratkozni az árváltozásokra is.

## Követelmények

- A rendszer több légitársaság és foglalási platform árait is lekérdezi.
- A felhasználó induló és célrepülőtér, valamint dátum szerint kereshet járatokat.
- A feliratkozott felhasználók e-mail értesítést kapnak áremelkedésről vagy árcsökkenésről.
- Az árak rendszeres időközönként automatikusan frissülnek.
